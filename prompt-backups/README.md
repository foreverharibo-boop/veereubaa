## 복구

사용자가 중복 정리 전으로 복구를 요청하면 이 파일의 내용으로 내장 `DEEPSEEK_KOREAN_PROMPT`만 복원합니다. 전체 저장소를 옛 커밋으로 되돌려 이후의 UI·기능 수정을 잃지 않도록 합니다. 현재 코드의 템플릿 문자열에 안전하게 넣고, 확장 버전과 서버 엔진을 일관되게 갱신하여 새 버전으로 배포합니다.

사용자가 직접 시험하려면 커스텀 번역기의 ‘딥식 플래시 전용’ 칸에 백업 내용 전체를 붙여 넣고 커스텀 번역기를 활성화할 수도 있습니다. 이 경우 저장한 커스텀 문구는 이후 업데이트로 덮어쓰지 않습니다. 현재 내장 지침으로 돌아오려면 해당 칸의 ‘기본값’을 누릅니다. 백업을 열거나 보관하는 것만으로는 적용되지 않습니다.
